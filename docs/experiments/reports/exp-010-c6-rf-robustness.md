关键物理规律如下：
1. **`B2`（单谐波/DC 比值法）随射频功率单调崩溃**：射频从 `Off` 增至 `13 dBm`（$J_0(m_{\mathrm{RF}})=0.3127$）时，`B2` 静态 RMS 由 `1.31°` 恶化至 `85.34°`（`0/8` 通过），并在 `Off_return` 后回落至 `1.67°`。
2. **`AffineFrozen` 与 `AffineRecal` 对 `10.1 dB` 贝塞尔共模对比度压缩完全免疫**：因 $J_0(m_{\mathrm{RF}})$ 同比例缩放一次与二次谐波，`AffineFrozen` 在不重新校准条件下从 `Off` 到 `13 dBm` 静态 RMS 始终稳定在 `0.981° ~ 1.011°`（含每工况 `17` 点单向 `DC PSI` 全局 `-0.68°` 扫频偏置与 `135°` 单点 `1.7°~2.2°` 边界贡献），其余 `7` 个目标稳定维持在 `0.2° ~ 1.1°`。在 `270°` 强偏置处，`B4` 在 `13 dBm` 下因未扣相干偏置使误差由 `+0.50°` 放大至 `+1.19°`，而 `AffineFrozen` 保持 `-0.35°`。
3. **`AffineS3Plus` 在低信噪比强压缩下的在线探测噪声敏感性**：在 `9–13 dBm` 下有效谐波降至 `31%`，`±20 mrad` 方波微扰探测估计器受热噪声抬升影响使 `45° / 135° / 315°` 扰动增至 `2°~3°`（静态 RMS 升至 `1.55° ~ 1.64°`），说明强 `J0` 压缩工况下需冻结增益或放大探测步长/平滑窗口，而不宜直接替代 `AffineFrozen` / `AffineRecal`。

## 4. 结论与台架边界

- 仿射算法（`AffineFrozen` / `AffineRecal`）在 `20 MHz` 射频引起 `h1_rel = 0.3127`（`-10.1 dB` 调制衰减）全过程中静态 RMS 稳定维持 `0.98° ~ 1.01°`（相对 `B2` 的 `85.34°` 提升两个数量级），且 `r < 0.15` 冻结保护在 `14.5 ~ 16.5 dBm` 零点穿零区间内实现零偏压滑脱。
- C6 中的 `-10 dB` 弱光工况因缺外接 VOA 维持 **待 VOA 补测**。
- 基于 C6 实测选择 **`9.0 dBm`**（`h1_rel = 0.6905`，满足 `|r - 1| = 0.310 > rho_thresh = 0.18` 的最低标准功率）作为 C5 扰动重校准触发激励。
- 门禁验证：`Post-C6 DG922 :OUTP1? = 0`、`analyze_and_plot --exp c6` 与 `check_repo_hygiene.py --working-tree --strict-doc-sync` 均通过。
